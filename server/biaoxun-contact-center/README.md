# 甲方情报台

独立运行在服务器 `127.0.0.1:6000`，由 Nginx 对外提供访问。后端读取现有 `biaoxun.notices`，数据库账号只保存在服务器环境变量中，不下发到浏览器。

## 功能

- 关键词、日期范围、读取条数筛选，可选正文搜索。
- 从“采购人信息 / 采购人（甲方） / 采购单位 / 招标人”等段落提取联系人、电话、邮箱和地址。
- 尽量截断代理机构段落，降低将代理联系方式误判为甲方联系方式的概率。
- 按甲方单位合并去重，支持仅显示有联系方式或显示全部单位。
- 导出带 UTF-8 BOM 的 CSV，可直接使用 Excel 打开。
- 登录保护、失败限流、CSRF 校验和 CSV 公式注入防护。

## 部署

- 应用目录：`/opt/biaoxun-contact-center`
- systemd：`biaoxun-contact-center.service`
- 监听地址：`127.0.0.1:6000`
- 健康检查：`/health`
